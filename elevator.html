Elevator Pitch

Our title is Church Search, a system designed to help individuals easily access their personal church records such as baptismal, confirmation, or marriage documents. As recommended by Maam Wenda, there is already an existing system for managing church records. Our task is not to create a new system, but to improve it by adding a QR code feature. Once scanned, the QR code will automatically display the person’s data, making the process faster and more convenient. However, as of now, we are still in the planning stage and thinking carefully about how we will implement the QR code feature. We are currently analyzing if it is possible, how it will connect to the existing system, and how we can ensure the security of personal data.

Team Reflection

"Most church search systems suffer from outdated records and poor mobile interfaces. We’ve developed a record-management search system with strict entry validation and real-time scanning. It ensures that when someone looks for a community, they get accurate, up-to-date results on a platform that actually works on their phone."

— The MindMesh Team
